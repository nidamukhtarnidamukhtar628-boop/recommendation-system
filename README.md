# 🎬 SmartRec — AI Movie Recommendation System

SmartRec is a content-based movie recommendation system that suggests similar movies using **TF-IDF** and **Cosine Similarity**. Built as a beginner-to-intermediate machine learning project, it combines a trained recommendation engine with a full Flask web application featuring user authentication and favorites.

## ✨ Features

- **Home page** with featured movies, navbar, and search bar
- **Search** movies by title with poster, genre, and rating
- **Content-based recommendations** — TF-IDF + Cosine Similarity suggest 5–6 similar movies for any title
- **Movie details page** with full overview, genres, rating, and similar movies
- **User authentication** — register, login, logout (Flask-Login, hashed passwords)
- **Favorites** — logged-in users can like/unlike movies with an animated heart icon
- **Responsive UI** — works on desktop, tablet, and mobile (Bootstrap 5)
- **Live movie posters** fetched from the TMDB API

## 🧠 How the Recommendation Engine Works

1. Movie `overview`, `genres`, and `keywords` are combined into a single text field (`tags`)
2. **TF-IDF Vectorizer** converts each movie's tags into a numeric vector (top 5000 features)
3. **Cosine Similarity** computes how similar every movie is to every other movie
4. Given a movie, the system returns the top N movies with the highest similarity score

Dataset used: [TMDB 5000 Movie Dataset](https://www.kaggle.com/datasets/tmdb/tmdb-movie-metadata) (4,802 movies)

## ⚙️ Setup Instructions

1. **Clone the repository**
```bash
   git clone https://github.com/nidamukhtarnidamukhtar628-boop/recommendation-system.git
   cd recommendation-system
```

2. **Install dependencies**
```bash
   pip install -r requirements.txt
```

3. **Generate the ML model files**
   Open and run `movie.ipynb` — this creates the `model/` folder with `tfidf.pkl`, `similarity.pkl`, and `movies.pkl` (these are excluded from the repo due to file size).

4. **Set up environment variables**
   Create a `.env` file in the root folder:

MYSQL_PASSWORD=your_mysql_password
TMDB_API_KEY=your_tmdb_api_key
SECRET_KEY=your_flask_secret_key


5. **Create the MySQL database**
```sql
   CREATE DATABASE smartrec_db;
```

6. **Run the app**
```bash
   python app.py
```
   Visit `http://127.0.0.1:5000`
